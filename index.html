🛡️ Privacy & Security

Access Token वाली बात — साफ जवाब

इस website में किसी का GitHub/Garena/access token माँगने, collect करने या server पर भेजने वाला feature नहीं रखा गया है। Access token password जैसा secret credential होता है। उसे किसी unknown site में paste करना सुरक्षित नहीं है।

अगर किसी service की API इस्तेमाल करनी हो, तो official OAuth/API flow और server-side secret management इस्तेमाल करना चाहिए — token को public HTML/JavaScript में hard-code नहीं करना चाहिए।

🔒 Demo rule: यह page credentials को कहीं upload नहीं करता।
