RAJA Official Website v2
==========================
1. Extract this ZIP.
2. Open index.html in a browser to test the site.
3. The site includes:
   - RAJA community home page
   - local player profile
   - public-profile/UID demo (user-provided data only)
   - built-in RAJA chatbot (offline/rule-based)
   - phone/play-style sensitivity helper
   - guides, news and official support links
4. No Garena password, OTP, private session token or private account data is requested.
5. The UID lookup is intentionally a demo. Do not claim it is a live Garena database.
6. To make the site public, upload these files to a static web host. A real AI chatbot or live public-data service would require a legitimate backend/API and should keep secrets on the server, never in script.js.
7. The project is independent and not affiliated with Garena.
